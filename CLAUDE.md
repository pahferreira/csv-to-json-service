# csv-to-json-service

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues and are tracked on a GitHub Project board, both via the `gh` CLI. Project commands need the `read:project` / `project` scope. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, used verbatim as label strings. Labels are canonical for triage; the board's `Kind` field mirrors them one-to-one and `Status` tracks workflow position. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
